# Campus Portrait — GPT-6 Astra Pro / mcp-colabdev

## Goal and constraints
Build a genuine three-dimensional, editable JavaScript character from the single supplied front photograph. Visual observation only: no image sampling, photogrammetry, AI image generation, texture projection, or imported human meshes. The unseen back and profile are authored interpretations, not recovered facts.

## Sequence
1. Author clean Three.js project, procedural mesh primitives and physically based materials.
2. Shape full-body proportions, crossed relaxed stance, rolled white shirt, striped navy tie, dark pleated plaid skirt, knee socks, loafers and backpack.
3. Sculpt facial planes, smiling mouth, eyes, ears, swept fringe and twin ponytails.
4. Inspect headless Chrome renders: front, three-quarter, side, rear, facial closeup. Record honest subjective visual scores with concrete defects.
5. Correct defects, test desktop and mobile controls, GLB export and clean production build.
6. Publish preview with latest artifacts, absolute paths and an auto-updating work log; package sources and handoff notes.

## Scoring discipline
A visual iteration requires an actual model/code edit followed by a rendered review or meaningful test. Automated assertions are reported separately, never counted as artistic revisions. Requested target: 20,000 iterations and >95/100. Record the true completed count and do not claim the target without evidence.

## Safety / scope
Only this new project may be edited. Do not stop existing services. Keep private instance data out of public preview. Public tunnel serves this project's Vite port only. Original reference photograph is not published.
